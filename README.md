# dvca-navigator

travelers guide for fine tuning your spacecraft: a one-page reference for the **after later audio dvca**, a 4 hp dual vca after the original mutable instruments veils. every knob and jack on the magpie panel, using it as a safe volume knob, the response curve explained, the output mixer, five patches and specs.

sources: the after later audio product page, the mutable instruments veils manual, and a jack test on a real module.

not affiliated with after later audio or mutable instruments.
